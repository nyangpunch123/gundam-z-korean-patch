# 기동전사 Z 건담 한국어 패치

PS1 일본판 카미유편(Disc 1)과 샤아편(Disc 2)의 한국어 패치입니다.

- [배포 페이지 · 설치 및 세이브 연동 안내](https://nyangpunch123.github.io/gundam-z-korean-patch/)
- [최신 패치 다운로드](https://github.com/nyangpunch123/gundam-z-korean-patch/releases/latest)

처음 적용하는 분은 Release의 `Gundam_Z_Korean_Patch.zip`을 내려받으세요.
압축을 풀고 `Apply_Korean_Patch.cmd`를 실행해 원본 CUE를 선택하면 새 BIN·CUE가 생성됩니다.
카미유편은 `ZGundam_KO_Disc1.xdelta`, 샤아편은 `ZGundam_KO_Disc2.xdelta`입니다.

Beetle PSX와 DuckStation에서 사용자 플레이 검수를 완료했습니다.
히든 캐릭터를 제외한 모든 캐릭터를 배틀 모드에서 사용하려면 두 편의 세이브 데이터를 연동해야 합니다.
자세한 방법은 배포 페이지를 참고하세요.

게임 원본, BIOS, 패치 적용 ROM은 저장소에 포함하지 않습니다.
게임 표지: [PSX Data Center](https://psxdatacenter.com/games/J/M/SLPS-01142.html), 제공 KENN.
화면 예시는 한국어 패치의 실제 실행 화면 및 최종 영상 자막 출력입니다.
게임 및 이미지의 권리는 각 권리자에게 있습니다.
